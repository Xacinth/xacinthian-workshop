# Xacinthian Workshop

Marketing site for Xacinthian Workshop, served via GitHub Pages. This repo contains only the public website (index.html) - no game code.

The website covers **Nightfall** (turn-based tactical RPG / guild sim) only.

The studio's **alchemy game** is an entirely separate project — a different title with its own report and files. It is temporarily staged in [`alchemy-game/`](alchemy-game/) pending its own repository, and is not part of Nightfall or this site.
