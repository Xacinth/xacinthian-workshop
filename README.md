# Xacinthian Workshop

Marketing site for Xacinthian Workshop, served via GitHub Pages. This repo contains only the public website (index.html) - no game code.

The website covers **Nightfall** (turn-based tactical RPG / guild sim) only.

The studio's alchemy/herbalism game, **Project Mortar**, is an entirely separate project with its own repository (`Xacinth/project-mortar` — private), roadmap, and design docs. Nothing in this repo or on the site refers to it; the two titles share vocabulary but no code, files, or reports.
